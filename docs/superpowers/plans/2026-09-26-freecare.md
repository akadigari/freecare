# freecare Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A one-page, browser-only checker that tells a Maryland patient whether state law says their hospital bill should be free or discounted, how long they have to apply, and what to bring.

**Architecture:** Four small pure modules (poverty line, dates, Maryland rules, form parsing, plain-English results) with Node's built-in tests, plus one static page that wires them to a form. No server, no build step, no dependencies, no network requests.

**Tech Stack:** Plain JavaScript ES modules, Node 22 `node --test`, static HTML and CSS served by `python3 -m http.server` for local preview.

**Spec:** `docs/superpowers/specs/2026-09-25-freecare-design.md`

## Global Constraints

- No npm dependencies. `package.json` exists only for `"type": "module"` and the test script.
- The page makes zero network requests: system fonts, no CDNs, no analytics.
- Poverty line 2026 (48 states and DC, HHS, published 2026-01-15): $15,960 for 1 person plus $5,680 per extra person.
- Rules: free at or below 200%; over 200% to 250% is 75% off; over 250% to 300% is 60% off; over 300% to 500% only with financial hardship: 50% (to 350), 45% (to 400), 40% (to 450), 35% (to 500). Hardship: medical bills over 12 months more than 25% of income. SNAP, WIC, Maryland Energy Assistance, or free or reduced-price school meals means free. Maryland residents only. 240 days from the first bill. Sources: Health-General 19-214.1, COMAR 10.37.13.06 (confirmed 2026-09-26: the 301% to 500% tiers apply only with financial hardship).
- Every result says it is a guide, not legal advice, and cites its sources.
- Return frozen objects; never mutate inputs.
- Zero em dashes in any file. Plain, high school English in all copy.
- No git commits without the owner's explicit OK (his standing rule). Leave work uncommitted.

## Review Focus

- Income typed as "$60,000" with a dollar sign, commas or cents: must parse (Task 4 test).
- A first-bill date near a daylight-saving change or late at night: day counts must not shift (Task 2 test, UTC date-only math).
- An income just over a cutoff shown as "200%" while the tier is 75% off: percent display must round up (Task 5 test).
- Medical bills left blank vs typed as 0: blank means unknown, no hardship, but the hint about hardship still shows between 300% and 500% (Task 5 test).
- A non-resident who checks SNAP: the state rule does not cover them (Task 3 test).

```js
// 2026 HHS poverty guidelines for the 48 contiguous states and DC.
// Published in the Federal Register on January 15, 2026. Update every January.
export const POVERTY_GUIDELINES = Object.freeze({
  year: 2026,
  firstPerson: 15960,
  eachExtraPerson: 5680,
  published: '2026-01-15',
  region: '48 contiguous states and DC',
  sourceUrl: 'https://aspe.hhs.gov/topics/poverty-economic-mobility/poverty-guidelines',
});

export const MIN_HOUSEHOLD = 1;
export const MAX_HOUSEHOLD = 20;

export function povertyLine(householdSize) {
  const isValid = Number.isInteger(householdSize)
    && householdSize >= MIN_HOUSEHOLD
    && householdSize <= MAX_HOUSEHOLD;
  if (!isValid) {
    throw new RangeError(`Household size must be a whole number from ${MIN_HOUSEHOLD} to ${MAX_HOUSEHOLD}.`);
  }
  return POVERTY_GUIDELINES.firstPerson + POVERTY_GUIDELINES.eachExtraPerson * (householdSize - 1);
}

export function percentOfPovertyLine(income, householdSize) {
  if (typeof income !== 'number' || !Number.isFinite(income) || income < 0) {
    throw new RangeError('Income must be a number that is 0 or more.');
  }
  return (income / povertyLine(householdSize)) * 100;
}
```

```js
const MS_PER_DAY = 86_400_000;
const ISO_DATE = /^(\d{4})-(\d{2})-(\d{2})$/;

export function parseIsoDate(iso) {
  const match = typeof iso === 'string' ? ISO_DATE.exec(iso) : null;
  if (!match) throw new RangeError('Dates must look like 2026-09-26.');
  const [year, month, day] = match.slice(1).map(Number);
  const ms = Date.UTC(year, month - 1, day);
  const check = new Date(ms);
  if (check.getUTCMonth() !== month - 1 || check.getUTCDate() !== day) {
    throw new RangeError('That date does not exist.');
  }
  return ms;
}

export function daysBetween(fromIso, toIso) {
  return Math.round((parseIsoDate(toIso) - parseIsoDate(fromIso)) / MS_PER_DAY);
}

export function addDays(iso, days) {
  return new Date(parseIsoDate(iso) + days * MS_PER_DAY).toISOString().slice(0, 10);
}

export function todayIso(now = new Date()) {
  const pad = (n) => String(n).padStart(2, '0');
  return `${now.getFullYear()}-${pad(now.getMonth() + 1)}-${pad(now.getDate())}`;
}
```

```js
// Maryland Health-General 19-214.1 and COMAR 10.37.13.06.
import { povertyLine, percentOfPovertyLine } from './poverty.js';
import { addDays, daysBetween } from './dates.js';

export const TIERS = Object.freeze({
  FREE: 'free',
  REDUCED: 'reduced',
  NOT_REQUIRED: 'not_required',
  NOT_COVERED: 'not_covered',
});

export const PROGRAM_KEYS = Object.freeze(['snap', 'wic', 'energyAssistance', 'schoolMeals']);
export const FREE_CARE_LIMIT = 200;
export const HARDSHIP_SHARE = 0.25;
export const APPLICATION_WINDOW_DAYS = 240;

// Over the previous cutoff, up to and including maxPercent.
const STANDARD_BANDS = Object.freeze([
  { maxPercent: 250, discount: 75 },
  { maxPercent: 300, discount: 60 },
].map(Object.freeze));

// Only for patients with financial hardship (COMAR 10.37.13.06).
const HARDSHIP_BANDS = Object.freeze([
  { maxPercent: 350, discount: 50 },
  { maxPercent: 400, discount: 45 },
  { maxPercent: 450, discount: 40 },
  { maxPercent: 500, discount: 35 },
].map(Object.freeze));

function assertAmount(value, label) {
  if (typeof value !== 'number' || !Number.isFinite(value) || value < 0) {
    throw new RangeError(`${label} must be a number that is 0 or more.`);
  }
}

export function hasHardship(medicalBills, income) {
  if (medicalBills === null || medicalBills === undefined) return false;
  assertAmount(medicalBills, 'Medical bills');
  assertAmount(income, 'Income');
  return medicalBills > income * HARDSHIP_SHARE;
}

export function discountFor(income, householdSize, hardship) {
  assertAmount(income, 'Income');
  const line = povertyLine(householdSize);
  const limit = (percent) => (line * percent) / 100;
  if (income <= limit(FREE_CARE_LIMIT)) return Object.freeze({ tier: TIERS.FREE, discount: 100 });
  const bands = hardship ? [...STANDARD_BANDS, ...HARDSHIP_BANDS] : STANDARD_BANDS;
  const band = bands.find((candidate) => income <= limit(candidate.maxPercent));
  return band
    ? Object.freeze({ tier: TIERS.REDUCED, discount: band.discount })
    : Object.freeze({ tier: TIERS.NOT_REQUIRED, discount: 0 });
}

export function applicationDeadline(firstBillIso, todayIso) {
  const daysSinceBill = daysBetween(firstBillIso, todayIso);
  if (daysSinceBill < 0) throw new RangeError('The first bill date cannot be in the future.');
  return Object.freeze({
    deadline: addDays(firstBillIso, APPLICATION_WINDOW_DAYS),
    daysSinceBill,
    daysLeft: Math.max(APPLICATION_WINDOW_DAYS - daysSinceBill, 0),
    isOpen: daysSinceBill <= APPLICATION_WINDOW_DAYS,
  });
}

export function checkEligibility(input, todayIso) {
  const {
    householdSize, income, isMarylandResident, programs = {},
    firstBillDate = null, medicalBillsLast12Months = null,
  } = input;
  if (typeof isMarylandResident !== 'boolean') throw new TypeError('Say whether you live in Maryland.');
  const percent = percentOfPovertyLine(income, householdSize);
  const presumptivePrograms = Object.freeze(PROGRAM_KEYS.filter((key) => programs[key] === true));
  const hardship = hasHardship(medicalBillsLast12Months, income);
  const shared = {
    householdSize,
    income,
    povertyLine: povertyLine(householdSize),
    percentOfPovertyLine: percent,
    presumptivePrograms,
    hardship,
    deadline: firstBillDate ? applicationDeadline(firstBillDate, todayIso) : null,
  };
  if (!isMarylandResident) return Object.freeze({ ...shared, tier: TIERS.NOT_COVERED, discount: 0 });
  if (presumptivePrograms.length > 0) return Object.freeze({ ...shared, tier: TIERS.FREE, discount: 100 });
  return Object.freeze({ ...shared, ...discountFor(income, householdSize, hardship) });
}
```

```js
import { parseIsoDate } from './dates.js';
import { PROGRAM_KEYS } from './rules.js';

const MONEY = /^\d+(\.\d{1,2})?$/;
const WHOLE = /^\d+$/;

function parseMoney(text) {
  const cleaned = String(text ?? '').replace(/[\s$,]/g, '');
  if (cleaned === '') return { value: null };
  return MONEY.test(cleaned) ? { value: Number(cleaned) } : { error: 'Enter an amount like 60,000.' };
}

function parseIncome(text) {
  const parsed = parseMoney(text);
  return parsed.value === null && !parsed.error
    ? { error: 'Enter your household income before taxes.' }
    : parsed;
}

function parseHouseholdSize(text) {
  const cleaned = String(text ?? '').trim();
  const size = WHOLE.test(cleaned) ? Number(cleaned) : Number.NaN;
  return size >= 1 && size <= 20
    ? { value: size }
    : { error: 'Enter how many people live in your household, from 1 to 20.' };
}

function parseResident(text) {
  if (text === 'yes') return { value: true };
  if (text === 'no') return { value: false };
  return { error: 'Pick yes or no.' };
}

function parseBillDate(text, todayIso) {
  if (!text) return { value: null };
  try {
    return parseIsoDate(text) > parseIsoDate(todayIso)
      ? { error: "The first bill date can't be in the future." }
      : { value: text };
  } catch (error) {
    return { error: error.message };
  }
}

export function parseForm(fields, todayIso) {
  const parsed = {
    householdSize: parseHouseholdSize(fields.householdSize),
    income: parseIncome(fields.income),
    resident: parseResident(fields.resident),
    firstBillDate: parseBillDate(fields.firstBillDate, todayIso),
    medicalBills: parseMoney(fields.medicalBills),
  };
  const errors = Object.fromEntries(
    Object.entries(parsed).filter(([, field]) => field.error).map(([key, field]) => [key, field.error]),
  );
  if (Object.keys(errors).length > 0) return Object.freeze({ ok: false, errors: Object.freeze(errors) });
  return Object.freeze({
    ok: true,
    input: Object.freeze({
      householdSize: parsed.householdSize.value,
      income: parsed.income.value,
      isMarylandResident: parsed.resident.value,
      programs: Object.freeze(Object.fromEntries(PROGRAM_KEYS.map((key) => [key, fields[key] === true]))),
      firstBillDate: parsed.firstBillDate.value,
      medicalBillsLast12Months: parsed.medicalBills.value,
    }),
  });
}
```

```js
import { POVERTY_GUIDELINES } from './poverty.js';
import { TIERS, APPLICATION_WINDOW_DAYS } from './rules.js';

export const SOURCES = Object.freeze([
  { label: 'Maryland Health-General § 19-214.1', url: 'https://mgaleg.maryland.gov/mgawebsite/Laws/StatuteText?article=ghg&enactments=false&section=19-214.1' },
  { label: 'COMAR 10.37.13.06', url: 'https://regs.maryland.gov/us/md/exec/comar/10.37.13.06' },
  { label: 'HHS 2026 poverty guidelines', url: POVERTY_GUIDELINES.sourceUrl },
].map(Object.freeze));

const PROGRAM_NAMES = Object.freeze({
  snap: 'SNAP',
  wic: 'WIC',
  energyAssistance: 'Maryland Energy Assistance',
  schoolMeals: 'free or reduced-price school meals',
});

const BRING = Object.freeze([
  "Proof of income, like pay stubs or last year's tax return",
  'Something that shows who lives in your household',
  'Your hospital bill',
]);

const NOTES = Object.freeze([
  'Hospitals can be more generous than this.',
  'Some hospitals also look at your savings.',
  'Every Maryland hospital uses the same financial assistance application.',
  'This is a guide, not legal advice.',
]);

const money = new Intl.NumberFormat('en-US', { style: 'currency', currency: 'USD', maximumFractionDigits: 0 });
const longDate = new Intl.DateTimeFormat('en-US', { dateStyle: 'long', timeZone: 'UTC' });

export function formatPercent(percent) {
  const roundedUp = Math.ceil(Number((percent * 10).toFixed(6))) / 10;
  return `${Number.isInteger(roundedUp) ? roundedUp : roundedUp.toFixed(1)}%`;
}

function joinNames(keys) {
  const names = keys.map((key) => PROGRAM_NAMES[key]);
  if (names.length <= 2) return names.join(' and ');
  return `${names.slice(0, -1).join(', ')}, and ${names.at(-1)}`;
}

function headlineFor({ tier, discount }) {
  if (tier === TIERS.FREE) return 'Your care should be free.';
  if (tier === TIERS.REDUCED) return `Your bill should be cut by ${discount}%.`;
  if (tier === TIERS.NOT_REQUIRED) return "Maryland law doesn't require a discount at your income. Ask anyway.";
  return "Maryland's rule is for Maryland residents. Check the hospital's own policy.";
}

function detailFor(result) {
  const { tier, presumptivePrograms, percentOfPovertyLine, hardship, householdSize } = result;
  if (tier === TIERS.NOT_COVERED) {
    return "Maryland's free and reduced-cost care rules cover Maryland residents. "
      + 'Many hospitals still help other patients through their own financial assistance policy.';
  }
  if (presumptivePrograms.length > 0) {
    return `Because you get ${joinNames(presumptivePrograms)}, you automatically qualify for free care.`;
  }
  const math = `Your household income is ${formatPercent(percentOfPovertyLine)} of the ${POVERTY_GUIDELINES.year} `
    + `federal poverty line (${money.format(result.povertyLine)} for a household of ${householdSize}).`;
  if (tier === TIERS.FREE) {
    return `${math} At or below 200%, Maryland hospitals have to give medically necessary care for free.`;
  }
  if (tier === TIERS.REDUCED && hardship && percentOfPovertyLine > 300) {
    return `${math} Because your medical bills from the last 12 months are more than 25% of your income, `
      + 'Maryland hospitals have to cut what you owe.';
  }
  if (tier === TIERS.REDUCED) return `${math} Between 200% and 300%, Maryland hospitals have to cut what you owe.`;
  if (percentOfPovertyLine <= 500) {
    return `${math} If your medical bills from the last 12 months are more than 25% of your income, `
      + 'you may qualify for a hardship discount of 35% to 50%.';
  }
  return `${math} Above 500%, the state rule doesn't require a discount, but many hospitals have their own programs.`;
}

function deadlineTextFor(deadline) {
  if (!deadline) return `You have ${APPLICATION_WINDOW_DAYS} days from your first bill to apply.`;
  if (!deadline.isOpen) {
    return `It's been more than ${APPLICATION_WINDOW_DAYS} days since your first bill. Ask the hospital anyway, some still help.`;
  }
  if (deadline.daysLeft === 0) return 'Today is the last day to apply.';
  const days = deadline.daysLeft === 1 ? '1 day' : `${deadline.daysLeft} days`;
  return `You have ${days} left to apply. The deadline is ${longDate.format(new Date(`${deadline.deadline}T00:00:00Z`))}.`;
}

export function describe(result) {
  const programProof = result.presumptivePrograms.length > 0
    ? [`Proof you get ${joinNames(result.presumptivePrograms)}`]
    : [];
  return Object.freeze({
    headline: headlineFor(result),
    detail: detailFor(result),
    deadlineText: deadlineTextFor(result.deadline),
    bring: Object.freeze([...BRING, ...programProof]),
    notes: NOTES,
    sources: SOURCES,
  });
}
```
